## 已验证承诺

干净源码检出仅依赖提交的规范化 CSV、GT 和 Python 依赖即可重算双工具归档指标；运行期间不需要网络、ignored 输入或分析数据库。两工具各 11 CWE 的原 all_non_gt 计数保持一致；新结果并列给出 in_scope、范围外计数和标准 fpr_in_scope。

本地验收通过全测试集与新装锁定依赖的干净副本；网络禁用探针、空 PATH 重放及图表实产证据保存在审计中。最终发布必须额外验证最终提交的 GitHub CI（Python 3.9 / 3.11）和发布资产校验值，结果附在 release 证据材料中。

## 已知限制

1. 这轮重放的是已保存的真实分析结果，不是重新执行分析器。固定版本重建数据库／执行规则未补验；所有平台的这种能力都不属于本最终版保证。旧 macOS/Linux 配置文档仅为历史参考。
2. CodeQL 的所选 SARIF 内嵌 2.25.3；CodeFuse CSV 没有可证明的历史分析器版本，清单保留 unknown。原始 Benchmark／CodeQL 导入提交和分析时精确规则提交也不完整，不将当前规则哈希或其他日期环境快照当作历史运行证明。
3. 指标只针对 OWASP Benchmark 1.2 固定 11 CWE，单位是 testcase_per_cwe。范围外计数按 CWE 分别去重后求和；不等于全项目唯一告警总数，不代表真实工程表现。Recall=1 不证明真实项目零漏报。
4. all_non_gt 的旧 fpr 是自定义比率而非标准 FPR。标准 FPR 缺分母或分母为零时返回 null；身份不明或不兼容报告不进行静默合并。
5. Python 依赖初次安装需要包源或 wheelhouse。固定依赖验收覆盖 Python 3.9 / 3.11，不承诺 Python 3.14 或任意更新版本。PNG 字节不承诺跨平台一致。第三方绘图依赖可能产生弃用提示。
6. 保留原有规则缺陷、FP 和原实验限制，不做新 CWE、工具、UI、共享污点框架大重构或“误报清零”扩展。

## 发布检查与证据包

最终提交检查：compileall、manifest 验证、完整 pytest、干净检出离线重放、完整 diff、历史证据 SHA256、四项修改／回滚材料。GitHub CI 完成且两个 Python job 均成功后，才创建 v3.0.1 release。

证据附件包含规范化输入、GT、版本／哈希、旧汇总、新双口径 JSON、每 CWE 明细、双语报告、图表、许可证和收尾审计。附 `SHA256SUMS`；下载后逐项校验，并从包内输入重放确认指标。release 的源码快照包含完整 Benchmark 源码和对应许可证，不在证据包中塞入数据库或分析器可执行文件。

发布资产的最终下载校验记录作为 release 附件及本地独立证据保存；它记录实际最终提交、CI run、资产清单和 SHA256，避免在发布前声称远端检查已完成。

## 归档是独立最后动作

发布完成不等于仓库已归档。所有门槛通过后，**先单独确认，再执行 GitHub 只读归档**；此目标阶段不自动操作该开关。

归档前确认：最终 release 与附件可下载且校验通过，CI 指向最终提交，已知限制完整，来源和许可证可检索。只读归档后停止 issue/PR/code 写入；如后续研究需要修改，使用另行维护的 fork。重新启用写入同样由用户明确决定。
